💡 使用步骤

  1. 点击右上角 ⚙ 全局配置，确认服务器公网地址正确（用于生成客户端配置）。
  2. 连接管理 → 用户分组 → 添加分组。
  3. 连接管理 → 连接配置 → 添加连接。
  4. 连接管理 → 连接配置 → 关联分组。
  5. 用户与权限 → 用户账号 → 添加用户（或从 LDAP 目录同步）。
  6. 下载用户配置文件，导入客户端连接测试。
